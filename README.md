# 📊 Excel Sales Dashboard

## 📌 Project Overview

An interactive Sales Dashboard created using Microsoft Excel to analyze sales performance across products, cities, regions, and sales representatives.

## 🛠️ Tools & Skills

- Microsoft Excel
- Power Query
- Pivot Tables
- Pivot Charts
- Slicers
- Data Cleaning
- Data Analysis
- Data Visualization
- Lookup Functions
- Conditional Formatting

## 📊 Key Analysis

- Total Sales
- Sales by Product
- Sales by City
- Sales by Region
- Sales Representative Performance
- Quantity and Revenue Analysis
- Interactive filtering using slicers

## 💡 Key Skills Demonstrated

- Data cleaning and transformation
- Data analysis
- Dashboard development
- Interactive reporting
- Data visualization
- Business-focused analysis

## 🎯 Objective

The objective of this project was to transform raw sales data into an interactive Excel dashboard that provides a clear overview of sales performance and helps identify trends and patterns.
